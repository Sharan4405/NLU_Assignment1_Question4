# Sports vs. Politics Classifier 🏀 🏛️

This project implements a text classification system to distinguish between **Sports** and **Politics** news articles. It compares three Machine Learning algorithms: Naive Bayes, Logistic Regression, and SVM.

## 📊 Results Summary
| Model | Accuracy |
| :--- | :--- |
| **SVM (Linear)** | **97.8%** |
| Logistic Regression | 97.2% |
| Naive Bayes | 96.5% |

## 🛠️ Tech Stack
* **Language:** Python 3.8+
* **Libraries:** Scikit-learn, Pandas, NumPy
* **Features:** TF-IDF Vectorization (Bi-grams)

## 🚀 follow the below steps to run the file
1. Clone the repo.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the script: `python b23ch1042_prob4.py`
